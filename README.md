# Práctica 3: React y Vue

Aplicación de personajes de Los Simpson construida con React y con Vue.

Nombre: Mateo Sebastián Namicela Jara

Requiere de Node.js 22.18 o superior.

## App en React

```bash
cd react-app
npm install
npm run dev
```

Pruebas:

```bash
npm test
```

## App en Vue

```bash
cd vue-app
npm install
npm run dev
```

Pruebas:

```bash
npm run test:unit
```
